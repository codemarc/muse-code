# Muse brand assets

Source: Muse's public website, https://muse.ai/, retrieved 2026-11-12.

- `muse-brand.svg`: https://muse.ai/images/landing/brand/muse-logo.svg, unchanged blue m artwork.
- `muse.svg` and toolbar variants: the same original path in a single-color editor-icon variant.
- `icon.png`: rasterized from the original vector path and published blue gradient.

Original logo gradient stops: #0082FB, #0064E0, #0040DC. Supporting light-blue #70BEFF comes from Muse's published blue palette.
